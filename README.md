# Healthcare Automation Testing Project

## Project Description
This project automates healthcare application test cases using Selenium and Java.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG / Cucumber
- Maven
- Apache POI
- GitHub

## Framework Design
- Page Object Model (POM)
- Data-driven testing
- Reusable utilities

## How to Run
1. Clone the repository
2. Import into Eclipse
3. Run testng.xml

## Reports
- Allure / Extent report generated after execution
